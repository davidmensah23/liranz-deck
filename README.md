# Liranz to the World: Observations, Strategy & Outcomes

An interactive, responsive 16-column Swiss International presentation deck presenting the 28-slide brand strategy and digital roadmap for Liranz.

## Features
- **Swiss International Grid & Typography**: Built on a strict 16-column grid with zero-border-radius design and International Klein Blue accents.
- **Embedded Playable Video Theater**: In-slide streaming video players for global brand benchmarks.
- **Interactive Lightbox Specimen Modals**: High-resolution brand guidelines, billboard, and website revamp previews.
- **Keyboard & Touch Navigation**: Full support for arrow keys, spacebar, swipe navigation, and fullscreen mode (`F`).
- **Responsive 1920x1080 Stage Scaling**: Auto-fitting layout with zero clipping across all screen sizes and aspect ratios.

## Quick Start
Open `index.html` directly in any modern browser, or serve locally:
```bash
npx serve .
```
